# Generated example audio

`generated-ambient-loop.mp3` is an original 8-second example loop synthesized from three sine waves (220, 275 and 330 Hz). No existing recordings, third-party samples or borrowed melody are used.

The generator and its output are dedicated under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). See [the full legal text](../../../licenses/CC0-1.0.txt).

Regenerate from the repository root with:

```sh
python3 tools/generate-example-audio.py "classes_first/rpg/sounds/generated-ambient-loop.mp3"
```

Regeneration requires Python 3 and ffmpeg. Playback uses the existing example API.
